How tickets are protected
  • Random serial. 8 characters drawn from about 850 billion combinations, so nobody can guess a valid one.
  • Signed QR. The QR carries an auth code made from your private key. A ticket made without the key fails at the gate.
  • Register check. Every ticket is in the register. The gate shows the holder's name to compare with their ID.
  • One entry. The first scan marks the ticket used. A screenshot shared with friends shows "Already used" with the time.
  • Transaction ID check. A payment ID that already has a ticket is flagged before a second one is issued.
  • Visual fingerprint. The 16 coloured squares and wave pattern on each ticket are unique and show on the gate screen too.
  • Void. Cancel a refunded or lost ticket from the Register. It stops working at once.
  • Keep the key private. Anyone who has it can create valid tickets.
