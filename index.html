GROOVE MODE — TICKET MANAGER

First Edition • Kampala, Uganda

Create a paid ticket

Record payment first, then issue the attendee's ticket. Each ticket receives a random ticket ID and token.

Ticket verification & gate check-in

Scan the attendee QR with a camera, or enter the ticket ID and verification code. The QR scanner needs an HTTPS website (or localhost) and camera permission.

Event settings

Settings affect new tickets. Previously issued tickets retain the details captured at issue time.

Prototype limitation: This demo stores tickets in this browser's local storage. It is not a shared online database. QR codes and IDs are unique within generated records, but validation from different devices, central anti-duplicate entry, secure remote payment confirmation and coordinated gate scanners require a hosted backend. Don't treat this local demo as a production fraud-proof ticketing system.
